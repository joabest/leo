# LEONNARDO

Front-end em Next.js + TypeScript + Tailwind para site institucional, mini-app público de pedidos e painel do artista.

## Rotas
- `/` — Home
- `/agenda` — Agenda de shows
- `/contratacao` — Orçamento/contratação
- `/disponibilidade` — Consulta mockada
- `/valores` — Tabela de valores
- `/pedidos` — App público de pedidos
- `/admin` — Dashboard desktop
- `/admin/mobile` — Painel mobile do artista

## Rodar
```bash
npm install
npm run dev
```

## Integrações futuras
A versão atual usa dados mockados e estado local. API, banco, pagamento, autenticação, WhatsApp/e-mail e realtime entram depois.
